# OIBSIP – Data Analytics Internship

## Level 2 – Task 2: Wine Quality Prediction

### Project Overview
This project focuses on analyzing wine quality data and building a Machine Learning model to predict wine quality based on its physicochemical properties.

### Objectives
- Explore and understand the wine quality dataset.
- Perform data preprocessing and exploratory data analysis.
- Build and evaluate a Machine Learning model.
- Analyze the factors that influence wine quality.

### Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
